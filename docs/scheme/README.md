## 三、信息交互约定（承接 Hub 仓 README §3，四方共同遵守）

1. **不写「通知 / 答复 / 评审」类文件** —— 它们是信件不是文档，读一次即失效却永久留存。
   四种内容的正确归宿：改了什么→契约修订记录；谁要回话→契约 §10；我方排期→本目录推进计划；
   要人立刻看见→commit message + 当面说。
2. **完成使命当次 `git mv` 到 `archive/`**，并在 `archive/README.md` 加一行，
   注明「**结论现在住在哪**」。不删除（契约修订记录会引用，删了断链）。
3. **新增文档前三问**：是事实源 / 推进计划 / 运维手册之一吗？能不能写进已有文档的某一节？
   什么时候可以归档？三问都过不了，说出来即可，不必落成文件。
